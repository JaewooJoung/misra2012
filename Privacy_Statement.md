# Privacy Statement - MISRA CodeGuard

**Last updated:** October 23, 2026

## 1. Overview
MISRA CodeGuard operates as an AI-powered code review assistant built within Microsoft 365 Copilot Agent Builder. This Privacy Statement outlines how information and code data are handled during interactions with the agent.

## 2. Data Collection and Processing
* **No External Data Collection:** The creators of this agent do not collect, store, log, or harvest any source code, queries, or personal data submitted by users.
* **Microsoft 365 Copilot Infrastructure:** All interactions, prompts, and code analyses are processed strictly within Microsoft 365 Copilot's secure Agent AI infrastructure, governed by your organization's enterprise security policies.

## 3. Knowledge Base
* The agent relies solely on embedded static coding knowledge (such as MISRA C:2012 guidelines) to provide technical code reviews. It does not export, retain, or utilize user data for external model training or tracking.

## 4. Security and Compliance
Because this agent operates entirely within your organization's Microsoft 365 tenant environment, it fully respects your corporate data boundaries, security controls, and compliance standards.

## 5. Contact Information
For any questions or concerns regarding this agent's privacy or operation, please contact your organization's internal IT or security administrator.
